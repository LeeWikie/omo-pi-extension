| Category | Meaning | Count |

## Coverage Notes

- Commands: covers built-in OpenCode commands plus repository-level OpenCode/Claude command prompt directories.
- Skills: covers the 17 shared skill directories identified under `packages/shared-skills/skills/`.
- Agents/Subagents: covers shared OMO personas plus OpenCode and Claude agent configuration directories.
- MCP servers/tools: covers built-in MCP registry, remote MCPs, local stdio MCPs, and tool registries.
- Hooks/Lifecycle: covers event routing, hook factory registry, grouped lifecycle hook families, and Codex hook descriptors.
- Config/session/installers/telemetry/assets: covers schema/loaders, session tools, platform installers, PostHog telemetry, docs, prompts, and templates.
